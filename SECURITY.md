# Security policy

Please report security or privacy vulnerabilities through GitHub's private
vulnerability reporting feature. Do not include credentials, private user data,
or an unpatched exploit in a public issue.

Kalima stores learning progress locally and must never weaken Android's keyguard
or bypass a PIN, password, or biometric check. Reports involving lock-screen
behavior, exported Android components, signing, backups, or unintended data
exposure should be treated as security-sensitive.

Security fixes are supported on the latest development version. Older local
release artifacts are retained for reproducibility but may not receive patches.
